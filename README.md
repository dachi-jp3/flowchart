# フロー図ツール

`index.html` 1ファイルだけで動く、スマホ対応のフロー図エディタです（外部ライブラリ・通信なし）。

## できること
- **枠（グループ）**: 図形をまとめる枠線。左上に名前を付けられ、枠線の色・背景色・実線/破線を変更可能。枠を動かすと中に入っている図形も一緒に動く（枠は配線の邪魔にならない）
- **色**: 塗り24色・枠線/線12色のパレットと、カラーピッカーによる自由な色指定（濃い色では文字が自動で白になる）
- **四角** と **丸（楕円）** をグリッド単位（1マス=20px）で配置・移動・サイズ変更
- **線** は図形同士（または空きマス）を結ぶだけで、**直角のみ**で自動配線（図形を避け、曲がりが少なく、他の線との重なりも避けるルート）
- 線の始点/終点の辺（上・右・下・左・自動）、矢印、破線、ラベルを指定可能
- 取り消し/やり直し、ピンチ拡大縮小、自動保存（ブラウザ内）
- JSON 保存/読み込み、SVG/PNG 書き出し
- GitHub のプライベートリポジトリへ JSON を保存/読み込み（Contents API、Personal Access Token 使用）

## スマホでの使い方
GitHub アプリ上の HTML はソース表示になり実行されないため、次のいずれかで開いてください。
1. `index.html` を **Raw** で開いて端末に保存（「ファイル」アプリ等）→ Safari/Chrome で開く
2. GitHub Pages で公開した URL から開く（下記）

図は **メニュー → GitHubへ保存** でこのリポジトリ（既定: `diagrams/flow.json`）にコミットできます。
トークンはリポジトリ限定の Fine-grained token（Contents: Read and write）を推奨します。

## 片手操作向けの工夫
- 操作ボタンはすべて画面下部（親指の届く範囲）に配置。元に戻す/やり直し、拡大縮小は画面の下隅に浮かぶボタン
- 図形を選ぶと下に操作バーが出て、「文字・色・形と大きさ・移動（矢印ボタンで1マスずつ）・線を引く・複製・削除」を1タップで呼び出せる。パネルは開いた分だけ表示されるので画面を広く使える
- 「線を引く」ボタンで、選択中の図形を始点にして、次にタップした図形へ配線
- 削除すると「元に戻す」ボタンが出る
- メニューの「左手モード」で、浮かぶボタンの左右を入れ替え
- 文字入力中はキーボードの上に入力欄が見えるよう画面を調整

## 操作
| ツール | 操作 |
|---|---|
| 四角 / 丸 | タップで配置、ドラッグで大きさ指定。もう一度押すと連続配置 |
| 枠 | タップで配置、ドラッグで範囲指定。縁か名前のタブをタップで選択して移動（中身も一緒に動く）。名前・色は下の操作バーから |
| 線 | 始点の図形→終点の図形をタップ（または始点からドラッグ）。空きマスをタップすると線の端をその位置に置ける |
| 選択 | ドラッグで移動、四隅の○で大きさ変更、ダブルタップで文字入力、線をタップで設定・端点の付け替え |
| 共通 | 2本指で拡大縮小/移動、選択ツールで余白をドラッグしても移動 |

PC では Delete で削除、Ctrl/⌘+Z で取り消し、Ctrl/⌘+Y でやり直し。

## GitHub Pages で公開する
`.github/workflows/pages.yml` により、プッシュのたびに `index.html` が Pages へ自動デプロイされます。
初回のみ、リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にしてください。
公開 URL: `https://dachi-jp3.github.io/flowchart/`

> 注意: Pages のサイトは、リポジトリが非公開でも URL を知っていれば誰でも見られます（Enterprise Cloud を除く）。
> 機密性のある図を GitHub へ保存する用途には向きません。
